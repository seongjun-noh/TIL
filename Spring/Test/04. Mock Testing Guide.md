## Mock vs Spy 비교

### 기본 개념
1. **Mock**
   - 완전한 가짜 객체
   - 기본적으로 모든 메서드가 아무 동작도 하지 않음
   - 명시적으로 동작을 정의한 메서드만 동작
   ```java
   @Test
   void mockExample() {
       // Mock 객체 생성
       UserService mockService = mock(UserService.class);
       
       // 특정 메서드의 동작 정의
       when(mockService.findById(1L)).thenReturn(new User("test"));
       
       // 정의하지 않은 메서드는 기본값 반환 (null, 0, false 등)
       assertNull(mockService.findById(2L));  // 정의되지 않은 동작
   }
   ```

2. **Spy**
   - 실제 객체를 감싸는 래퍼(wrapper)
   - 기본적으로 실제 객체의 메서드가 그대로 동작
   - 필요한 메서드만 선택적으로 동작을 재정의
   ```java
   @Test
   void spyExample() {
       // 실제 객체 생성
       UserService realService = new UserService(userRepository);
       
       // Spy 객체 생성
       UserService spyService = spy(realService);
       
       // 특정 메서드만 동작 재정의
       doReturn(new User("test")).when(spyService).findById(1L);
       
       // 재정의하지 않은 메서드는 실제 객체의 동작 수행
       spyService.sendEmail();  // 실제 이메일 발송 로직 실행
   }
   ```

### 주요 차이점

#### 1. 기본 동작
```java
public class UserService {
    public String getUsername(Long id) {
        return "Real User";
    }
}

@Test
void mockVsSpy() {
    // Mock 객체
    UserService mockService = mock(UserService.class);
    assertEquals(null, mockService.getUsername(1L));  // 아무 동작도 정의하지 않았으므로 null 반환
    
    // Spy 객체
    UserService spyService = spy(new UserService());
    assertEquals("Real User", spyService.getUsername(1L));  // 실제 메서드 호출
}
```

#### 2. 메서드 동작 정의
```java
@Test
void defineBehavior() {
    // Mock: when().thenReturn() 사용
    UserService mockService = mock(UserService.class);
    when(mockService.getUsername(1L)).thenReturn("Mock User");
    
    // Spy: doReturn().when() 사용 권장
    UserService spyService = spy(new UserService());
    doReturn("Spy User").when(spyService).getUsername(1L);
}
```

## Mockito 주요 기능

### Mock 객체 생성
```java
@ExtendWith(MockitoExtension.class)
class MockitoTest {
    // @Mock 어노테이션으로 Mock 객체 생성
    @Mock
    private UserRepository userRepository;
    
    // @InjectMocks로 의존성 주입
    @InjectMocks
    private UserService userService;
    
    // mock() 메서드로 직접 생성
    private PaymentService paymentService = mock(PaymentService.class);
}
```

### 메서드 동작 정의
```java
@Test
void defineMethodBehavior() {
    // 기본 반환값 설정
    when(userRepository.findById(1L)).thenReturn(Optional.of(new User()));
    
    // 예외 발생 설정
    when(userRepository.save(any())).thenThrow(new RuntimeException());
    
    // 연속된 호출에 대한 다른 반환값 설정
    when(userRepository.count()).thenReturn(1L, 2L, 3L);
    
    // void 메서드 동작 정의
    doNothing().when(userRepository).delete(any());
    doThrow(new RuntimeException()).when(userRepository).delete(any());
}
```

### 메서드 호출 검증
```java
@Test
void verifyMethodCalls() {
    // 메서드 호출 여부 검증
    verify(userRepository).findById(1L);
    
    // 호출 횟수 검증
    verify(userRepository, times(2)).findAll();
    
    // 호출 순서 검증
    InOrder inOrder = inOrder(userRepository);
    inOrder.verify(userRepository).save(any());
    inOrder.verify(userRepository).findAll();
    
    // 호출되지 않았음을 검증
    verify(userRepository, never()).delete(any());
}
```

### 인자 매처
```java
@Test
void argumentMatchers() {
    // 정확한 값 매칭
    when(userRepository.findById(1L)).thenReturn(Optional.of(new User()));
    
    // any() 매처
    when(userRepository.save(any(User.class))).thenReturn(new User());
    
    // anyString() 매처
    when(userRepository.findByEmail(anyString())).thenReturn(Optional.of(new User()));
    
    // 커스텀 매처
    when(userRepository.findByAge(argThat(age -> age > 18)))
        .thenReturn(Arrays.asList(new User()));
}
```

## 실전 예제

### 서비스 계층 테스트
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock
    private UserRepository userRepository;
    
    @Mock
    private EmailService emailService;
    
    @InjectMocks
    private UserService userService;
    
    @Test
    void createUser_ValidInput_ReturnsUser() {
        // given
        UserDto userDto = new UserDto("test@test.com", "password");
        User savedUser = new User("test@test.com", "password");
        when(userRepository.save(any())).thenReturn(savedUser);
        doNothing().when(emailService).sendWelcomeEmail(any());
        
        // when
        User result = userService.createUser(userDto);
        
        // then
        assertEquals("test@test.com", result.getEmail());
        verify(userRepository).save(any());
        verify(emailService).sendWelcomeEmail(any());
    }
}
```

### 컨트롤러 테스트
```java
@WebMvcTest(UserController.class)
class UserControllerTest {
    @Autowired
    private MockMvc mockMvc;
    
    @MockitoBean
    private UserService userService;
    
    @Test
    void createUser_ValidInput_Returns201() throws Exception {
        // given
        UserDto userDto = new UserDto("test@test.com", "password");
        when(userService.createUser(any())).thenReturn(new User());
        
        // when & then
        mockMvc.perform(post("/api/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(userDto)))
                .andExpect(status().isCreated());
    }
}
```

## 모범 사례

### Mock 사용이 적합한 경우
- 외부 시스템과의 통신이 필요한 객체 (DB, API 등)
- 복잡한 의존성을 가진 객체
- 모든 동작을 완전히 통제하고 싶을 때

### Spy 사용이 적합한 경우
- 실제 객체의 일부 메서드만 수정하고 싶을 때
- 실제 객체의 동작을 대부분 유지하고 싶을 때
- 특정 메서드의 호출만 가로채고 싶을 때
