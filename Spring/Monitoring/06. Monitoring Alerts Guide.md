## 1. Grafana 알림 규칙

### 알림 규칙 설정
```yaml
# 메모리 사용량 알림
- name: "높은 메모리 사용량"
  condition: "jvm_memory_used_bytes{area='heap'} / jvm_memory_max_bytes{area='heap'} * 100 > 85"
  duration: "5m"
  severity: "warning"
  message: "힙 메모리 사용량이 85%를 초과했습니다"

# CPU 사용량 알림
- name: "높은 CPU 사용량"
  condition: "system_cpu_usage > 0.8"
  duration: "5m"
  severity: "warning"
  message: "CPU 사용량이 80%를 초과했습니다"

# 에러율 알림
- name: "높은 에러율"
  condition: "sum(rate(http_server_requests_seconds_count{status=~'5..'}[5m])) / sum(rate(http_server_requests_seconds_count[5m])) * 100 > 5"
  duration: "5m"
  severity: "critical"
  message: "HTTP 에러율이 5%를 초과했습니다"
```

## 2. 알림 채널 연동

### Slack 연동
```yaml
apiVersion: 1
kind: NotificationChannel
metadata:
  name: slack-notifications
spec:
  type: slack
  settings:
    url: https://hooks.slack.com/services/YOUR/SLACK/WEBHOOK
    recipient: "#monitoring-alerts"
    username: "Grafana Alert"
    icon_emoji: ":warning:"
    message_format: "{{ .Title }}\n{{ .Message }}\n{{ .Error }}"
```

### Email 연동
```yaml
apiVersion: 1
kind: NotificationChannel
metadata:
  name: email-notifications
spec:
  type: email
  settings:
    addresses: "team@example.com"
    subject: "[{{ .Status }}] {{ .AlertRuleName }}"
    message: |
      Alert: {{ .Title }}
      Status: {{ .Status }}
      Severity: {{ .Labels.severity }}
      Time: {{ .StartsAt }}
      Message: {{ .Message }}
```

### 웹훅 연동
```yaml
apiVersion: 1
kind: NotificationChannel
metadata:
  name: webhook-notifications
spec:
  type: webhook
  settings:
    url: "https://api.example.com/alerts"
    httpMethod: "POST"
    username: "grafana"
    password: "${WEBHOOK_PASSWORD}"
```

## 3. 임계값 설정

### 시스템 메트릭 임계값
```yaml
thresholds:
  cpu:
    warning: 70
    critical: 85
  memory:
    warning: 80
    critical: 90
  disk:
    warning: 85
    critical: 95
  
metrics:
  - name: "CPU 사용률"
    query: "system_cpu_usage"
    warning: ${thresholds.cpu.warning}
    critical: ${thresholds.cpu.critical}
    
  - name: "메모리 사용률"
    query: "jvm_memory_used_bytes / jvm_memory_max_bytes * 100"
    warning: ${thresholds.memory.warning}
    critical: ${thresholds.memory.critical}
    
  - name: "디스크 사용률"
    query: "disk_used_bytes / disk_total_bytes * 100"
    warning: ${thresholds.disk.warning}
    critical: ${thresholds.disk.critical}
```

### 애플리케이션 메트릭 임계값
```yaml
thresholds:
  response_time:
    warning: 1000  # ms
    critical: 3000 # ms
  error_rate:
    warning: 1     # %
    critical: 5    # %
  request_rate:
    warning: 100   # rps
    critical: 200  # rps

metrics:
  - name: "응답 시간"
    query: "rate(http_server_requests_seconds_sum[5m]) / rate(http_server_requests_seconds_count[5m]) * 1000"
    warning: ${thresholds.response_time.warning}
    critical: ${thresholds.response_time.critical}
    
  - name: "에러율"
    query: "sum(rate(http_server_requests_seconds_count{status=~'5..'}[5m])) / sum(rate(http_server_requests_seconds_count[5m])) * 100"
    warning: ${thresholds.error_rate.warning}
    critical: ${thresholds.error_rate.critical}
    
  - name: "초당 요청 수"
    query: "sum(rate(http_server_requests_seconds_count[5m]))"
    warning: ${thresholds.request_rate.warning}
    critical: ${thresholds.request_rate.critical}
```

## 4. 알림 정책

### 알림 우선순위
```yaml
priorities:
  p1:
    description: "즉각적인 조치 필요"
    response_time: "15분 이내"
    notification_channels:
      - slack-urgent
      - phone-call
      - email-urgent
    
  p2:
    description: "업무 시간 내 조치"
    response_time: "4시간 이내"
    notification_channels:
      - slack-normal
      - email-normal
    
  p3:
    description: "계획된 유지보수"
    response_time: "24시간 이내"
    notification_channels:
      - email-normal
```

### 에스컬레이션 정책
```yaml
escalation_policies:
  - name: "Critical 알림"
    initial_delay: "15m"
    steps:
      - wait: "5m"
        notify: ["team-lead"]
      - wait: "10m"
        notify: ["manager"]
      - wait: "15m"
        notify: ["director"]
    
  - name: "Warning 알림"
    initial_delay: "30m"
    steps:
      - wait: "15m"
        notify: ["team-lead"]
      - wait: "30m"
        notify: ["manager"]
```
