## 1. ELK 스택 개요

### 아키텍처
```mermaid
graph LR
    A[애플리케이션] --> B[Logstash]
    B --> C[Elasticsearch]
    C --> D[Kibana]
```

### 각 컴포넌트 역할
1. **Logstash**: 로그 수집 및 가공
   - 다양한 소스로부터 데이터 수집
   - 데이터 변환 및 필터링
   - JSON 형식으로 정규화
2. **Elasticsearch**: 로그 저장 및 검색
   - 분산 검색 엔진
   - 실시간 분석
   - REST API 제공
3. **Kibana**: 로그 시각화 및 분석
   - 대시보드 생성
   - 데이터 시각화
   - 고급 분석 도구

### 시스템 요구사항
- **Elasticsearch**:
  - 최소 8GB RAM
  - Java 11 이상
  - SSD 스토리지 권장
- **Logstash**:
  - 최소 4GB RAM
  - Java 11 이상
- **Kibana**:
  - 최소 2GB RAM
  - Node.js

## 2. 설치 및 설정

### Elasticsearch 설정
```yaml
# elasticsearch.yml
cluster.name: my-application
node.name: node-1
path.data: /var/lib/elasticsearch
path.logs: /var/log/elasticsearch
network.host: 0.0.0.0
http.port: 9200

# 보안 설정
xpack.security.enabled: true
xpack.security.transport.ssl.enabled: true
xpack.security.transport.ssl.verification_mode: certificate
xpack.security.transport.ssl.keystore.path: elastic-certificates.p12
xpack.security.transport.ssl.truststore.path: elastic-certificates.p12

# 클러스터 설정
discovery.seed_hosts: ["host1", "host2"]
cluster.initial_master_nodes: ["node-1"]

# 메모리 설정
-Xms2g
-Xmx2g

# 캐시 설정
indices.memory.index_buffer_size: 30%
indices.queries.cache.size: 20%
```

### Logstash 설정
```conf
# logstash.conf
input {
  file {
    path => "/logs/application.log"
    type => "spring-boot-logs"
    codec => json
    sincedb_write_interval => "10s"
    start_position => "beginning"
    stat_interval => "1s"
  }
  beats {
    port => 5044
  }
}

filter {
  if [type] == "spring-boot-logs" {
    json {
      source => "message"
    }
    
    date {
      match => [ "timestamp", "yyyy-MM-dd HH:mm:ss.SSS" ]
      target => "@timestamp"
    }
    
    grok {
      match => { "message" => "%{LOGLEVEL:log_level} %{GREEDYDATA:log_message}" }
    }
    
    mutate {
      add_field => {
        "environment" => "production"
        "application" => "spring-boot-app"
      }
    }
  }
}

output {
  elasticsearch {
    hosts => ["localhost:9200"]
    index => "spring-logs-%{+YYYY.MM.dd}"
    user => "elastic"
    password => "${ELASTIC_PASSWORD}"
    ssl => true
    cacert => "/etc/logstash/certs/ca.crt"
  }
  
  # 디버깅용 stdout 출력
  stdout {
    codec => rubydebug
  }
}
```

### Kibana 설정
```yaml
# kibana.yml
server.port: 5601

# 보안 설정

```

## 3. 로그 수집 설정

### Spring Boot 애플리케이션 설정
```xml
<!-- logback-spring.xml -->
<configuration>
    <appender name="JSON_FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>logs/application.log</file>
        <encoder class="net.logstash.logback.encoder.LogstashEncoder">
            <includeMdcKeyName>requestId</includeMdcKeyName>
            <includeMdcKeyName>userId</includeMdcKeyName>
        </encoder>
    </appender>

    <root level="INFO">
        <appender-ref ref="JSON_FILE" />
    </root>
</configuration>
```

### 로그 포맷
```json
{
  "@timestamp": "2024-03-19T10:00:00.000Z",
  "level": "INFO",
  "thread": "main",
  "logger": "com.example.Application",
  "message": "Application started",
  "requestId": "123e4567-e89b-12d3-a456-426614174000",
  "userId": "user123"
}
```

## 4. Kibana 대시보드 설정

### 인덱스 패턴 설정
1. Management > Stack Management 이동
2. Index Patterns > Create index pattern
3. Pattern name: `spring-logs-*` 입력
4. Time field: `@timestamp` 선택

### 기본 대시보드 구성

## 5. 운영 관리

### 1. 인덱스 관리
```bash
# 오래된 인덱스 삭제 (30일)
curator_cli --host localhost delete_indices \
    --filter_list '[{"filtertype":"age","source":"creation_date","direction":"older","unit":"days","unit_count":30}]' \
    --filter_list '[{"filtertype":"pattern","kind":"prefix","value":"spring-logs-"}]'
```

### 2. 백업 설정
```bash
# 스냅샷 생성
curl -X PUT "localhost:9200/_snapshot/backup/snapshot_1?wait_for_completion=true"

# 스냅샷 복원
curl -X POST "localhost:9200/_snapshot/backup/snapshot_1/_restore"
```

### 3. 모니터링 알림 설정
```json
{
  "trigger": {
    "schedule": {
      "interval": "5m"
    }
  },
  "input": {
    "search": {
      "request": {
        "indices": ["spring-logs-*"],
        "body": {
          "query": {
            "bool": {
              "must": [
                { "match": { "level": "ERROR" }},
                { "range": { 
                    "@timestamp": { 
                      "gte": "now-5m" 
                    }
                  }}
              ]
            }
          }
        }
      }
    }
  },
  "condition": {
    "compare": {
      "ctx.payload.hits.total": {
        "gt": 10
      }
    }
  },
  "actions": {
    "slack_webhook": {
      "webhook": {
        "url": "https://hooks.slack.com/services/xxx/yyy/zzz",
        "message": "5분간 {{ctx.payload.hits.total}}개의 에러가 발생했습니다."

    }
  }
}
```

## 6. 문제 해결

### 일반적인 문제
1. **Elasticsearch 메모리 부족**
   ```bash
   # elasticsearch.yml 수정
   -Xms4g
   -Xmx4g
   ```

2. **로그 수집 지연**
   ```conf
   # logstash.conf 튜닝
   input {
     file {
       sincedb_write_interval => "10s"
       stat_interval => "1s"
     }
   }
   ```

3. **인덱스 용량 관리**
   ```bash
   # 인덱스 설정 최적화
   curl -X PUT "localhost:9200/spring-logs-*/_settings" -H 'Content-Type: application/json' -d'
   {
     "index": {
       "number_of_replicas": 1,
       "refresh_interval": "30s"
     }
   }'
   ```

## 9. 보안 강화

### SSL/TLS 설정
```bash
# 인증서 생성
bin/elasticsearch-certutil cert -out elastic-stack-ca.p12 -pass ""

# 노드 인증서 생성
bin/elasticsearch-certutil cert --ca elastic-stack-ca.p12 --out elastic-certificates.p12 --pass ""
```

### 사용자 인증 설정
```yaml
# elasticsearch.yml
xpack.security.enabled: true
xpack.security.authc:
  realms:
    native:
      native1:
        order: 0
```

### 감사 로그 설정
```yaml
xpack.security.audit.enabled: true
xpack.security.audit.logfile:
  events.include: ["authentication_success", "authentication_failure", "access_denied", "connection_denied"]
  events.exclude: ["system_access_granted"]
```
