## 1. 기본 설정

### 의존성 추가

#### Maven
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

#### Gradle
```gradle
implementation 'org.springframework.boot:spring-boot-starter-actuator'
```

## 2. 주요 엔드포인트

### 기본 제공 엔드포인트
- `/actuator/health`: 애플리케이션 건강 상태
  - 데이터베이스 연결 상태
  - 디스크 공간
  - 커스텀 헬스 체크
- `/actuator/metrics`: 애플리케이션 메트릭
  - JVM 메트릭
  - 시스템 메트릭
  - 애플리케이션 메트릭
- `/actuator/info`: 애플리케이션 정보
  - 빌드 정보
  - Git 정보
  - 환경 정보
- `/actuator/prometheus`: Prometheus 메트릭
- `/actuator/env`: 환경 설정 정보
- `/actuator/loggers`: 로깅 설정
- `/actuator/mappings`: 요청 매핑 정보
- `/actuator/threaddump`: 스레드 덤프
- `/actuator/heapdump`: 힙 덤프

## 3. 상세 설정

### application.yml 기본 설정
```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,metrics,info,prometheus
      base-path: /actuator
      cors:
        allowed-origins: "*"
        allowed-methods: GET,POST
  endpoint:
    health:
      show-details: always
      show-components: always
    metrics:
      enabled: true
    prometheus:
      enabled: true
  info:
    env:
      enabled: true
    java:
      enabled: true
    os:
      enabled: true
```

### 보안 설정
```yaml
spring:
  security:
    user:
      name: actuator
      password: ${ACTUATOR_PASSWORD}
      roles: ACTUATOR_ADMIN

management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics
    jmx:
      exposure:
        exclude: "*"
```

## 4. 커스텀 메트릭 추가

### Counter 메트릭 예시
```java
@Component
public class CustomMetrics {
    private final Counter requestCount;
    
    public CustomMetrics(MeterRegistry registry) {
        this.requestCount = Counter.builder("app.requests")
            .description("요청 수 카운터")
            .tag("type", "total")
            .register(registry);
    }
    
    public void incrementRequestCount() {
        requestCount.increment();
    }
}
```

### Timer 메트릭 예시
```java
@Component
public class RequestTimer {
    private final Timer requestTimer;
    
    public RequestTimer(MeterRegistry registry) {
        this.requestTimer = Timer.builder("app.request.duration")
            .description("요청 처리 시간")
            .tag("api", "user")
            .register(registry);
    }
    
    public void recordRequestTime(long timeMs) {
        requestTimer.record(timeMs, TimeUnit.MILLISECONDS);
    }
}
```

## 5. 커스텀 헬스 체크

```java
@Component
public class CustomHealthIndicator implements HealthIndicator {
    
    @Override
    public Health health() {
        try {
            // 헬스 체크 로직
            return Health.up()
                .withDetail("message", "서비스 정상")
                .withDetail("timestamp", System.currentTimeMillis())
                .build();
        } catch (Exception e) {
            return Health.down()
                .withException(e)
                .build();
        }
    }
}
```

## 6. 모범 사례

1. 보안

   - 민감한 정보 마스킹

2. 성능
   - 메트릭 수집 간격 최적화
   - 불필요한 엔드포인트 비활성화
   - 대용량 데이터 캐싱

3. 모니터링
   - 중요 메트릭 식별 및 우선순위화
   - 알림 임계값 설정
   - 로깅 전략 수립
