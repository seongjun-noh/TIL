## 테스트의 기초

### 테스트의 중요성
- 코드의 품질 보장
- 리팩토링 시 안전성 확보
- 문서화 역할
- 설계 개선

### 테스트 종류
1. 단위 테스트 (Unit Test)
   - 개별 컴포넌트의 독립적인 테스트
   - [Mock 객체](04.%20Mock%20Testing%20Guide.md#mock-vs-spy-비교)를 활용한 격리된 테스트
   - 빠른 실행 속도

2. 통합 테스트 (Integration Test)
   - 여러 컴포넌트 간의 상호작용 테스트
   - 실제 데이터베이스나 외부 서비스 사용
   - 전체 시스템의 동작 검증

3. 기능 테스트 (Functional Test)
   - 실제 사용자 시나리오 기반 테스트
   - 엔드투엔드 테스트
   - UI/UX 검증

## 스프링 부트 테스트 환경 설정

### 의존성 추가
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```

### 테스트 프로파일 설정
```yaml
# application-test.yml
spring:
  jpa:
    hibernate:
      ddl-auto: create
  datasource:
    url: jdbc:h2:mem:testdb
    driver-class-name: org.h2.Driver
    username: sa
    password:
```

## 스프링 부트 테스트 어노테이션

### 테스트 구성
- `@SpringBootTest`: 전체 애플리케이션 컨텍스트 로드
- `@WebMvcTest`: Web 계층 관련 빈만 로드
- `@DataJpaTest`: JPA 관련 설정만 로드

### 목 객체 관련
- `@MockitoBean`: 스프링 빈을 목 객체로 대체
- `@SpyBean`: 실제 객체를 스파이로 감싸기

### 설정 관련
- `@TestConfiguration`: 테스트용 설정 클래스
- `@ActiveProfiles`: 활성화할 프로파일 지정

### 트랜잭션 관련
- `@Transactional`: 테스트 트랜잭션 처리
- `@Commit`: 테스트 후 커밋 강제

## 테스트 작성 모범 사례

### 테스트 구조화
1. Given (준비)
   - 테스트 데이터 준비
   - [Mock 객체 동작 정의](04.%20Mock%20Testing%20Guide.md#메서드-동작-정의)
   - 테스트 환경 설정

2. When (실행)
   - 테스트 대상 메서드 호출
   - API 엔드포인트 호출
   - 비즈니스 로직 실행

3. Then (검증)
   - [결과값 검증](03.%20JUnit%205%20Guide.md#테스트-검증)
   - [Mock 객체 호출 검증](04.%20Mock%20Testing%20Guide.md#메서드-호출-검증)
   - 예외 발생 검증

### 테스트 네이밍 컨벤션
- 메서드명_테스트조건_기대결과
- 예: `createUser_ValidInput_ReturnsUser()`

## 실습 예제

### 단위 테스트 예제
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock
    private UserRepository userRepository;
    
    @InjectMocks
    private UserService userService;
    
    @Test
    void createUser_ValidInput_ReturnsUser() {
        // given
        UserDto userDto = new UserDto("test@test.com", "password");
        User savedUser = new User("test@test.com", "password");
        when(userRepository.save(any())).thenReturn(savedUser);
        
        // when
        User result = userService.createUser(userDto);
        
        // then
        assertEquals("test@test.com", result.getEmail());
        verify(userRepository).save(any());
    }
}
```

### 통합 테스트 예제
```java
@SpringBootTest
@AutoConfigureMockMvc
class UserControllerTest {
    @Autowired
    private MockMvc mockMvc;
    
    @Autowired
    private UserRepository userRepository;
    
    @Test
    void createUser_ValidInput_Returns201() throws Exception {
        // given
        UserDto userDto = new UserDto("test@test.com", "password");
        
        // when & then
        mockMvc.perform(post("/api/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(userDto)))
                .andExpect(status().isCreated())
                .andExpect(jsonPath("$.email").value("test@test.com"));
    }
}
```
